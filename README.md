# Meeting to Actions

Extract decisions and assigned work from meeting notes with supporting quotes.

## Use in ChatGPT or Claude

Copy the instructions from [SKILL.md](SKILL.md) into a conversation and supply your material. In an Agent Skills environment, install the entire folder using that environment's skill loader.

## Try it

Lead: I will send the brief on Friday. Designer: Maybe we should record a demo.

**Expected behavior**

One action for Lead due Friday. The demo remains a proposal.
